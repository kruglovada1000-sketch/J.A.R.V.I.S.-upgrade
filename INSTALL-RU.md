# Установка JARVIS // KODA

## Что потребуется

1. Node.js 20 или новее.
2. Google Chrome или Microsoft Edge.
3. Claude Code, установленный и авторизованный.
4. Микрофон.

ElevenLabs не обязателен. Без него JARVIS использует системное распознавание и голос браузера.

## Как получить готовую сборку

Открой вкладку **Actions** в этом репозитории, выбери workflow **Build JARVIS KODA** и скачай artifact `jarvis-koda-ready` после успешной сборки.

## Первый запуск

Распакуй архив, открой терминал в папке проекта и выполни:

```bash
npm install
npm run setup
npm start
```

После запуска открой адрес из терминала, обычно `http://localhost:5173`, именно в обычном Chrome/Edge. Разреши микрофон и нажми `INITIALISE`.

## Режим безопасности

Обычный запуск:

```bash
npm start
```

Опасные действия по умолчанию ограничены.

Режим с разрешением действий через инструменты:

```bash
npm run bridge:writes
```

Не включай его постоянно. Он нужен только когда осознанно требуется управление браузером/телефоном или изменение данных.

## Что подключим позже

- GitHub — `ohrana.tech`, `Upgrade`, `J.A.R.V.I.S.-upgrade`;
- Chrome/browser tools — проверка живого сайта;
- Android — работа с телефоном;
- поисковые и медиа-инструменты при необходимости.

JARVIS читает локальные MCP-серверы из `~/.claude.json`. Если инструмент там не настроен, JARVIS его не увидит.
