# Установка JARVIS // KODA

## Что потребуется

Общее для обоих режимов:

1. Node.js 20 или новее.
2. Google Chrome или Microsoft Edge.
3. Микрофон.

Для режима **OpenAI / GPT** нужен `OPENAI_API_KEY`.
Для режима **Claude** нужен установленный и авторизованный Claude Code.

ElevenLabs не обязателен. Без него JARVIS использует системное распознавание и голос браузера. Для русскоязычного ответа наша версия автоматически выбирает установленный русский системный голос, если он есть.

## Как получить готовую сборку

Открой вкладку **Actions** в этом репозитории, выбери workflow **Build JARVIS KODA** и скачай artifact `jarvis-koda-ready` после успешной сборки.

## Первый запуск

Распакуй архив, открой терминал в папке проекта и выполни:

```bash
npm install
npm run setup
```

### Запуск с GPT / OpenAI — Windows PowerShell

Сначала задай API-ключ только для текущего окна PowerShell:

```powershell
$env:OPENAI_API_KEY="ТВОЙ_OPENAI_API_KEY"
npm run start:openai
```

По умолчанию используется модель `gpt-5.6-sol`. При необходимости можно выбрать другую:

```powershell
$env:JARVIS_OPENAI_MODEL="gpt-5.6-terra"
npm run start:openai
```

### Запуск с GPT / OpenAI — macOS/Linux

```bash
export OPENAI_API_KEY="ТВОЙ_OPENAI_API_KEY"
npm run start:openai
```

### Запуск через Claude Code

```bash
npm run start:claude
```

Обычный `npm start` тоже оставлен в режиме Claude для совместимости с исходным JARVIS.

После запуска открой адрес из терминала, обычно `http://localhost:5173`, именно в обычном Chrome/Edge. Разреши микрофон и нажми `INITIALISE`.

## Что уже работает в OpenAI-режиме

- OpenAI Responses API как мозг;
- память диалога внутри текущего подключения;
- русский рабочий контекст «Лейтенант КОДА»;
- существующий голосовой интерфейс JARVIS;
- русский системный голос для кириллицы, если он установлен;
- прерывание ответа голосом/интерфейсом;
- безопасная локальная WebSocket-связь с интерфейсом.

На первом этапе OpenAI-режим отвечает и говорит, но ещё не управляет GitHub/Chrome/Android. Эти инструменты подключаются следующим этапом. Claude-режим сохраняет исходные MCP-возможности оригинального проекта.

## Безопасность

API-ключ не записывай в GitHub и не вставляй в исходные файлы. Передавай его только через переменную окружения на своём компьютере.

Для Claude-режима опасные действия по умолчанию ограничены. Режим записи включай только осознанно.

## Примеры голосовых команд после запуска

- «Джарвис, ты меня слышишь?»
- «Джарвис, кто ты?»
- «Что мы сегодня делаем с ohrana.tech?»
- «Объясни коротко, что такое canonical».

После подключения инструментов добавим рабочие команды:

- «Проверь ohrana.tech»;
- «Проверь мобильную версию»;
- «Найди битые ссылки»;
- «Сверь sitemap»;
- «Сравни main с живым сайтом»;
- «Подготовь файлы для FileZilla».
