# J.A.R.V.I.S. // KODA

Наша рабочая версия JARVIS для проектов ЧОО «Рускорпорация».

## Два режима мозга

- **OpenAI / GPT** — запускается командой `npm run start:openai` и использует OpenAI Responses API.
- **Claude Code** — запускается командой `npm run start:claude` и сохраняет совместимость с исходным JARVIS и его MCP-инструментами.

Обычный `npm start` пока оставлен Claude-режимом для совместимости.

## Уже сделано

- русский рабочий контекст «Лейтенант КОДА»;
- переключение GPT / Claude без смены интерфейса;
- GPT-мост, совместимый с WebSocket-протоколом оригинального JARVIS;
- сохранение памяти диалога OpenAI в пределах текущего подключения;
- автоматический выбор русского системного голоса для кириллицы, если такой голос установлен;
- прерывание ответа;
- CI-сборка, health-check и интеграционный тест полного пути GPT-ответа через транспорт JARVIS;
- готовый artifact `jarvis-koda-ready` после успешной GitHub Actions сборки.

## Основные задачи проекта

- работа с `ohrana.tech`;
- работа с репозиторием `Upgrade`;
- GitHub и безопасные правки через отдельные ветки;
- SEO, sitemap, canonical, 404 и проверка ссылок;
- Lighthouse и контроль мобильной версии;
- браузерные проверки;
- голосовой интерфейс;
- следующим этапом — инструменты GitHub, Chrome и Android в OpenAI-режиме.

## Основа

Проект основан на `adewaskar/jarvis` (MIT License) и адаптируется собственным слоем JARVIS // KODA. Свежая версия исходного JARVIS клонируется во время сборки, после чего поверх неё автоматически накладывается наша кастомизация.

## Безопасность

По умолчанию — чтение, анализ и проверки. Удаление, публикация, отправка, установка, деплой и другие действия с последствиями выполняются только после явного разрешения.

API-ключи не хранятся в репозитории.
